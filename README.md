# 달살림 소개 사이트

**달살림** — 살림을 한곳에 적는 종합 가계부 — 을 소개하는 사이트다. 주소는 `https://dalsalim.dabutdev.com`.

앱 저장소와 따로 둔다. 이 저장소는 앱의 코드도 데이터도 읽지 않는다.

## 명령어

```bash
npm install
npm run dev      # http://localhost:3000
npm run build    # 타입 검사 + 정적 파일을 out/ 에 만든다
npm run lint
npm run format   # prettier --write .
```

## 어떻게 만들어지나

Next.js 의 **정적 내보내기**다 (`next.config.ts` 의 `output: "export"`). 빌드할 때 모든 페이지가 HTML 로 만들어져
`out/` 에 놓이고, 서버 없이 그 폴더만 올리면 된다. 검색 엔진은 완성된 HTML 을 읽는다.

```
src/
  app/          페이지 — 폴더가 곧 주소다
  components/   머리 · 꼬리말 · 로고처럼 여러 페이지가 같이 쓰는 조각
  config/       사이트 이름 · 주소 · 문의처 · 바깥 링크
  styles/       디자인 토큰 (색 · 간격 · 모서리 · 폭)
```

## 배포 (Cloudflare Pages)

| 칸          | 값                    |
| ----------- | --------------------- |
| 빌드 명령   | `npm run build`       |
| 내보낼 폴더 | `out`                 |
| 환경 변수   | `NODE_VERSION` = `22` |

## 지킬 것

- **색 · 간격 · 모서리는 `src/styles/tokens.css` 의 변수로만 쓴다.** 값은 달살림 앱의 것을 옮겨 적었다.
  컴포넌트에 hex 를 직접 적으면 어둡게에서 깨진다.
- **방문자에게서 아무것도 받지 않는다.** 방문 분석 · 쿠키 · 입력 칸 · 바깥 스크립트 · 바깥 글꼴을 넣지 않는다.
  넣게 되면 개인정보 처리방침에 적을 것이 생긴다 — 넣기 전에 그것부터 정한다.
  브라우저에 저장하는 것은 밝게 · 어둡게로 고른 값 하나뿐이고 어디로도 보내지 않는다.
- **약관 · 방침 · 계정 삭제 안내의 본문을 여기에 복사하지 않는다.** 원본은 앱 서버에 한 벌뿐이고, 꼬리말이 그 페이지로 보낸다
  (`src/config/site.ts` 의 `LEGAL_LINKS`).
- **화면 그림에는 지어낸 값만 쓴다.** 실제 금액 · 사람 이름 · 가게 이름 · 결제 알림을 싣지 않는다.
- **다른 회사의 로고를 쓰지 않는다.** 스토어 배지 대신 글자 버튼, 카드사 대신 머리글자 타일이다.

### 문구

- 해요체로 쓴다 (`~해요` · `~예요`).
- **달살림은 소비를 평가하지 않는다.** 「절약」 「아껴요」 「달성」 「점수」 「많이 쓴 사람」 같은 말로 앱을 소개하지 않는다.
- **앱이 분류를 골라 준다고 쓰지 않는다.** 결제 알림은 「넣을지는 직접 고르거나 자동으로 넣게 할 수 있다」까지만 말한다.
- 붉은 글자는 「지난달보다 늘어난 금액」 한 곳에만 쓴다. 지출 자체에는 쓰지 않는다.
